historical pins and vendor shell pipes. Two neutral-hook fixtures treated native

also lagged behind the scripts. A real PowerShell footer regression used `exit 1`

published installer hashes separately from source candidate hashes. Rethrow errors
and test the caller survives. Run the new native backend, launcher and cleanup

remaining Content-Length at EOF. AST fixture functions also need their real package
context so relative helper imports execute rather than becoming source-unvalidated.
