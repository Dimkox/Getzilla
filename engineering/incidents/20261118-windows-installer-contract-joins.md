The exact 9ab Windows job reported eleven failures. Installer tests still expected
historical pins and vendor shell pipes. Two neutral-hook fixtures treated native
Windows commands as plaintext POSIX commands. The source installer digest record
also lagged behind the scripts. A real PowerShell footer regression used `exit 1`
and could close a caller that evaluated the installer in its session.

Keep named installer intent, test exact current release routing, select the native
hook field and decode launcher data when checking its target. Preserve immutable
published installer hashes separately from source candidate hashes. Rethrow errors
and test the caller survives. Run the new native backend, launcher and cleanup
controls in the Windows job; a Linux skip does not qualify Windows.

The shared HTTP reader set a timeout on a socket already closed by HTTPResponse.
Skip that mutation after completion, keep deadline checks, and refuse positive
remaining Content-Length at EOF. AST fixture functions also need their real package
context so relative helper imports execute rather than becoming source-unvalidated.

The retained installer log lost the reason before pip's final PyYAML error. Preserve
bounded redacted first and last output and exact arguments in the existing command
artifact. Current wheel availability and an isolated dry-run succeeded; they do not
prove the historical CI cause or qualify a complete installation.
