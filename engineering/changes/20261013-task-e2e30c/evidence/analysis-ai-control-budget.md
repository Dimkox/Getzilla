## Rollback and real human steps

Source rollback keeps live paid execution disabled. Additive state migrations preserve reservations/audit; do not roll back by deleting spend evidence or restoring env fallback. Drain unknown operations by reconciliation before re-enable.

Source tests can prove policy decisions and fake boundary execution. They cannot prove that a native host loaded the hook, that every host tool emits an inner pre-execution event, that the agent cannot edit its enforcement policy, that a provider revoked a key, or that a deployed scheduler/service uses this revision.
