The existing `getzilla_factory.local_writer.LocalWriter` accepts optional `tcp_connect_ports=(PORT,)`. In its existing child startup path, Linux Landlock ABI4 permits TCP connections only to the declared admission endpoint and refuses explicit TCP binds. The restriction is inherited by the native client and descendants across exec. Connected parent sockets are not inherited. The port policy joins the existing command/check identity, so changing it cannot reuse a saved successful run. There is no new runner, rotator or grant ledger.

This must be composed with a trusted model admission endpoint on one loopback port, with Ollama on a different port. The client must not connect directly to the backend to bypass per-request validation/accounting. Apply the same restrictions to writer, reviewer, auxiliary and fallback native clients. The existing continuation policy still owns candidate admission and task budgets. Do not claim a standalone Qwen invocation has this protection. A TCP allowlist alone neither validates a model request nor proves a finite model request budget; the endpoint integration remains required before ordinary admission.

Require a distinct namespace, only loopback, no external route, a successful local socket and an intentionally denied external control. A shared namespace blocks external routing but does not itself block direct loopback backend access; the inherited Landlock layer supplies that restriction. Missing ABI4 or failed enforcement must stop launch.
