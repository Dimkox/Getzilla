# Exact dependency license exceptions

The six automatic licenses and the 72-hour acquisition limit stay unchanged.
`dependency_exceptions` is an optional bounded list in the project license
policy. Each closed entry pins one package version, wheel filename and SHA256,
official artifact URL, source manifest SHA256, use, resolved distribution,
delivery kind, stable named target profile and ABI. A renewed index, run or
source HEAD needs fresh evidence but does not belong in this static policy.

Only two immutable condition profiles are supported:

- `cffi-2.1.1-mit0-inline-mit-v1` retains the entire MIT-0 license and the
  separate complete inline MIT notice in `cffi/_cffi_gen_src.py`. The separately
  pinned CP313 wheel uses `cffi-2.1.1-cp313-mit0-inline-mit-v1` and has the
  same complete legal and inline notice bytes.
- `typing-extensions-4.16.0-history-unchanged-v1` retains the entire 13,936-byte
  PSF, BeOpen, CNRI, CWI and documentation 0BSD history. It also requires the
  original `typing_extensions.py` bytes in an observed installation or output.
  Modified distributions need a separate reviewed changes-summary profile.

The verifier pins full original file hashes in its closed profile records.
Fixtures retain the actual wheels, metadata and complete source/legal members.
The result records `policy-exception-conditions-verified` separately from the
ordinary license selection. It preserves the original license diagnostic.
Assurance remains `artifact-integrity-only`.

Every existing origin, freshness, artifact identity, source pin, Python target,
dependency closure and output custody check still applies. CI installation
profiles bind the stable recipe path; live source/run/image bindings remain
mandatory. Factory output scopes are rederived from its verified parent
source/declaration, CPython 3.12 profile and complete actual archive composition.
These scopes do not cover the original source uses or other targets.

Certifi MPL, psycopg LGPL and bundled binary components, and setuptools bundled
LGPL/MPL remain pending. Their owner-approved preparation does not supply
missing full terms, source mappings or retention evidence. No generic binary
source obligation is inferred from a `.so` suffix. This policy supplies no
human security approval or external CI authority.

Family license findings retain their original closed artifact record and the
complete original component proof JSON. The final report can rederive the
family identity, component proof hash, term ownership and origin witness
bindings. Action, tool and image findings use this separate closed form.
Neither form accepts a label-only or empty family result.

The configured host typing scopes match the observed CPython 3.12 host.
The CI CPython 3.13 entries are future expectations for the declared base,
not an observed runtime or ABI claim. They qualify only after the existing
live observer proves that exact target and the held image reader proves
all required installed members. The named Factory output remains CPython 3.12.
