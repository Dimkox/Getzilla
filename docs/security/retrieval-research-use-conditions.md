# Exact private research source-use conditions

The optional research profile has one fixed project manifest and one exact
private, unmodified, unshipped use. It does not change the six automatic license
families. Existing ordinary package policy, origin checks and execution guards
remain independent.

`.getzilla/config/retrieval-research-runtime-v1.json` fixes 29 inference wheels,
two separate inspection-only wheels, both model revisions/assets, the codec,
Python 3.12.15 ABI and selected OCI identity. Inspection-only artifacts are not
installed by the source-use adapter. Fixed inert package/image condition
catalogs contain exact metadata, complete original notice/grant identities and
the selected image's 105 package notices. The package reader streams at most
262145 bytes before its fixed digest/schema checks, including SDKzip loading.
Both actual catalog resources must participate in source/admission binding.

The research entries reuse the existing exact dependency-exception evaluator.
Legacy metadata values and absent values remain exact original values; they are
not globally normalized. Tokenizers and flatbuffers need actual supplemental
source grants. Certifi/tqdm need the full MPL terms; regex and NumPy retain their
complete additional terms. Every supplemental proof keeps the original four
files/262144-byte bound. The full ONNX Runtime notice remains an original wheel
member, not a falsely downsized supplemental proof.

`require_public_research_use(root,registration_path)` reads a closed private
registration containing artifact/model/terms roots and an optional software
root. All roots stay within the current project's owned runtime. Original
evidence roots remain private0700; original hash-pinned files may be0400 or0600.
It performs no extraction, installation, network request or native/model import.
`required_public_research_layout(root)` gives fixed logical names and pins;
materialization must copy the already verified original bytes into that layout.
It never changes old acquisition files or their permissions.

The adapter holds an actual root reader and binds the current route owner,
context, source and current evidence identities. It verifies exact wheel bytes,
saved registry origin, original metadata/full grant/notice members, and retained
source conditions. If an extracted software root is provided, every member and
directory must match the exact archive-derived closure; extra code and empty
directories, links, missing/changed files and custody changes refuse. The
preparation states are `archive-custody-source-use-admitted` and
`extracted-software-held`. Archive-only state cannot permit native imports.

`check_public_research_use(ref)` rechecks current owner/source/module state and
held evidence. The immutable opaque reference is not constructible from JSON
or serializable. Its model/image pins are requirements for the owned supervisor,
not a claim that a multi-GB model was rehashed as supplemental license evidence.
Model, image and exported-copy integrity still need actual current observation.
Call `close_public_research_use(ref)` when its owning operation ends or is
revoked. Source-use conditions are not a renewable model execution lease.

Read-only inference exports are separate from originals. The supervisor must
bind those derived copies and their actual isolation/resource/target facts.
Before native inspection imports, genuine A, exact conditions, explicit INSPECT
operation admission and the actual owned resource are required. Genuine
independent B based on real graph/tokenizer/loader/runtime facts additionally
precedes all ranks. Existing freshness/vulnerability and native admission checks
are not replaced by this source-use reference.

The catalogs retain publisher-declared source association, not a cryptographic
compilation assertion. No full native SDK or static/dlopen membership is claimed.
The four uninspected Windows `.a` contents and absent PyPI wheel build
provenance remain limitations. Another use, changed target, modification,
redistribution or published image needs its own actual conditions and custody.
This profile grants no Trust CI/human security approval, model recommendation,
enterprise access or production activation.

Private tiny tests use a separate code-owned `_Composition` through the same
actual current-owner and held-file path. The public production checker rejects
their references. They never claim to qualify the real runtime or models.

Supplemental grants remain held/current in the private host evidence graph for the unshipped internal operation. Existing wheel notices remain exact software members. No fourth mount or redistributed artifact is inferred from that limited custody scope.

The inert preparation command is `python3 scripts/getzilla_research_materialize.py
--root PROJECT --sources PRIVATE_SOURCE_MAP --output
.getzilla/runtime/scratch/FRESH_NAME`. Use the real current owner session. The
scratch parent must already exist. The source map contains paths only. Its exact
440 keys must match the fixed catalog:29 wheel archives,29 saved indices,
referenced model assets,codec,5 image blobs and357 retained source/legal files.
The helper checks their fixed sizes and SHA256 values. It creates one new0700
layout with0400 source/software files and a0600 closed registration. It refuses
a reused destination and leaves a failed partial output for inspection.

The helper validates all wheel members and every RECORD row, ZIP shape, names,
file kinds, special modes and cross-wheel collisions. It preserves all3685
software files (179121964bytes), including inert`.pth`,entrypoint metadata and
`.data` members. It never runs installation rules, processes`.pth`, creates
entrypoint scripts, remaps`.data`, imports wheel code or emits a use-condition
reference. The helper rechecks the full derived software tree, including all hashes and
directories, under the original preparation deadline. This is an extracted byte
projection; it makes no installed ABI or native execution claim.

The separate inert preparation bounds are180seconds,12GiB output bytes,
3GB per acquired file,4000 derived software files,8192 whole-layout entries and
256MiB derived software bytes. The helper checks free disk before copying and
uses no-follow held source/output descriptors. It preserves original files.
These bounds do not change public source/candidate/query limits or the four-file,
262144-byte supplemental proof limit. Corpus BSD/MIT notices stay retained legal
artifacts; they add no corpus source candidates. Read-only inference exports are
a separate supervisor step after actual owner admission.
