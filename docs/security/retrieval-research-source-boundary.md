# Public retrieval research source boundary

The optional `retrieval-research` data profile is disabled by default. Its
source-checkout CLI is `scripts/getzilla_retrieval_experiment.py`. Status loads
no model or source corpus. Input audit requires module selection and remains a
draft consistency observation. Execution refuses with
`native_publication_unbound`; no ranker, model loader or native review issuer
is attached. `getzilla_retrieval_inputs.py` and `DraftAudit.require_rankable`
keep their existing refusal.

`retrieval.research.public_source_cut` is a fixed local public-source host. It
requires the actual current OS/task owner, current policy and selected module.
It binds the two original public catalog hashes and commits before reading any
source. Only exact candidate paths and matching bytes can enter a cut. It
stages a fresh private copy and holds its descriptors through the context;
source custody, catalog, route, policy and module changes invalidate the cut.
No request flag or alternative catalog can enroll private data.

The inventory remains bounded to4,000 paths,32MiB aggregate and1MiB/file.
Each fresh batch has at most128 source files within the unchanged native broker
limits of128 documents,8MiB and two seconds. These source cuts grant no encoder,
output, long index lifetime or remote disclosure permission. Output admission
always refuses. The production Factory128-file/262KiB/two-second profile is
unchanged. An expired cut cannot be renewed into a model lease.

`getzilla_agent.py report` can bind a report to a frozen private four-file
input dataset with `--report-path`, `--dataset-path` and `--dataset-sha256`.
The fixed input order is function-universes, partition, queries, full-qrels
(each with `.json`). The digest is SHA256 of compact sorted-key UTF-8 JSON of
`[{"name":...,"sha256":...,"bytes":...}, ...]` in that order. Report/input
bytes and inode metadata are captured and rechecked under existing task and
agent-generation locks. Private runtime files must have safe ownership/modes.
The observation stores hashes and paths, not report text. Rebinding differs
from idempotent replay and is rejected. `terminal_report_binding` rechecks the
same current task, generation, dataset and custody before consumption.

This observation is explicitly `local-observation-only`. CLI labels, local
start/stop records and report bytes do not prove an independent native child
or report delivery. The opaque PhaseA/B types have no production issuer.
Actual native publication remains unavailable. The distinct [operator-witnessed public review action](public-review-witness.md)
requires current owner publication and complete scientific checks. It grants
reviewed-data facts only. No actual corpus witness is claimed here.

No real corpus seal, artifact/window PhaseB, model resource admission, scientific
primary eligibility, production ACL qualification or provider activation follows
from these source controls. Tests use a separately named tiny source fixture;
it does not qualify the real corpus or create a native review issuer.
