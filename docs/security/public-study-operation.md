# Fixed public-study operation

The default remains off. No operation, model, source cut, result or review can
be imported from JSON as authority. These source APIs do not activate a runtime.

The current task owner calls
`register_public_study_operation(root, operation, registration_path, A, use_ref, B=None)`.
The source-use owner supplies `use_ref` through its current held-file API.
INSPECT requires current A, the exact extracted-software-held source-use profile
and explicit owner intent. RANK also requires genuine independently reviewed B.
All tokenizer/model imports additionally require the actual owned supervisor's
live resource and the fixed stage check. This is private public-source research
consent, not human/security approval, general Factory admission or redistribution.

The closed registration has `schema_version:1`,
`kind:"public-study-operation/v1"`, `operation` (inspect_public_artifacts or
rank_public_study), `phase_a_sha256`, `phase_b_sha256` (null for INSPECT),
`conditions_sha256`, `artifact_manifest_sha256` and `runtime`.

Runtime has exactly: inference_image_id, inspection_image_id,
docker_executable, docker_sha256, daemon_id, model_root, software_root,
worker_root, artifact_files, software_files, worker_files, cpu_ids,
hard_timeout_seconds, resource_profile_sha256, base_image_digest and
recipe_digest. Root paths are relative owned runtime export paths. File pins
are ordered [relativePath, exactBytes, rawSHA256] triples. They must equal the
fixed condition/source owner inventories; caller lists cannot substitute code
or models. Both image IDs match the source-use profile's exact OCI config;
the selected base manifest remains bound. An unproved custom image is refused.

Use exactly three readonly exports: /worker, /software and /model. Keep their
outer parent0700, every export directory0555 and each owned single-link file0444.
Do not chmod original evidence. The condition owner keeps the original complete
supplemental terms host-side. The supervisor verifies export bytes and native
readback before imports. An operation's metadata snapshot expressly does not
claim streamed model integrity, live resources or native SDK completeness.

The supervisor consumes only an opaque operation ref. Its frozen projection
binds the exact source, runtime, artifacts, image, local Docker executable,
CPU IDs, resource profile and original hard timeout. It uses the existing
execution owner and actual execution ID. Checkpoints do not renew a two-second
source cut or the original whole-job deadline.

The stable holdout intent/label derives from the frozen dataset and experiment
configuration. The existing protected execution registry reserves that label
across tasks and principals in this workspace. Any different operation ID,
including a failed or unknown earlier attempt, refuses another holdout. A
same-operation duplicate uses the existing CAS and cannot respawn. This adds no
permission journal or claim store and does not assert cross-workspace ownership.

`reviewed_public_study_inputs` returns data only: the four current dataset
documents, fixed experiment configuration, immutable model facts and B manifest

`witness_public_inspection(root, registration_path, A, inspect_opref, result_ref)`.
The result must be the actual supervisor's opaque result for that SAME original
INSPECT ref and existing terminal execution/artifact record. Diagnostic JSON,
source-only review, status strings and declared native IDs do not replace it.

The closed publication request has schema_version1,
kind operator-public-inspection/v1, manifest (exact file reference), and reviews.
Each review publication has annotation, reports, delivery and delivery_assurance.

kind independent_public_study_inspection_review_v1, reviewer, manifest_sha256,
coverage, decision, findings, rationale and limitations. Coverage must include
all of tokenizers/windows/graphs/runtime/codec/resources; supported findings
must be complete and independent of the actual inspection owner.

real readback and confirmed cleanup. It changes no dataset row flag. Observed
unavailable/failed/not-started/uncertain outcomes can be retained separately and
never mint B. Missing or unexecuted inspection facts remain distinct. The fixed
six-arm plan permits no automatic subset, precision replacement, denominator
shrink or best-run selection: absent complete B, ranks stay unavailable and the
experiment is inconclusive.
